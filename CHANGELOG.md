# Changelog

## 0.1.0 (2026-11-16)

First public version.

- Full AWS-style console pages for S3, DynamoDB, EC2 (with ELB and Auto Scaling), Aurora and RDS, and AWS Glue.
- Basic pages (`/legacy/`) for ECS, ECR, EKS, MSK, ElastiCache, Redshift, DocumentDB, Neptune, Athena, Kinesis, Lambda, SQS, SNS, EventBridge, Step Functions, IAM, Secrets Manager, Parameter Store, CloudWatch Logs and CloudFormation.
- API Explorer for any operation of any service.
- `start.sh` one-command start; `server.py` local-only API bridge with a CSRF guard.
